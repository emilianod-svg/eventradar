# Placeholders por categoría

Este directorio contiene únicamente `generic.svg` como placeholder inicial.
El set completo de placeholders por categoría (música, feria, cine, deporte,
gastronomía, municipal, otro — sección 2.1 del plan) queda pendiente hasta
que el equipo defina el estilo visual definitivo. No se generaron imágenes
de eventos reales ni ficticias en esta inicialización.
